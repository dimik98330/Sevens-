# Размещение Sevens

Один Render Web Service: Node.js 22, Free, Frankfurt. Build:
`npm ci && npm run build`; start: `npm run start:cloud`.
Next слушает Render `PORT`, API — только `127.0.0.1:18080`.
При отказе одного процесса launcher завершает оба.

Neon PostgreSQL хранит постоянные данные и вложения в `attachment_blobs`.
Локальный `/tmp` используется только для проверки загрузки.

## Перенос данных

1. Сохранить `pg_dump -Fc --no-owner --no-acl` и uploads.
2. Восстановить dump в новую пустую базу через `pg_restore`
   с `--no-owner --no-acl --exit-on-error`. Существующие таблицы не стирать.
3. Применить миграции: `npm run db:migrate` с прямым TLS URL Neon.
4. Указать облачный `DATABASE_URL`, абсолютный исходный `UPLOAD_DIR`;
   выполнить `npm run storage:import`. Проверяются размер и SHA-256.
5. Проверить, что все активные вложения имеют `storage_backend=database`
   и запись в `attachment_blobs`; сверить счётчики таблиц с исходной базой.
6. Оставить dump и исходные файлы в резервной копии.

Работающий сайт использует pooled TLS URL. Миграции аддитивные,
сериализованы advisory lock. Launcher не запускает seed и не сбрасывает
пользователей, пароли или идеи.

## Настройки Render

- `DATABASE_URL`: PostgreSQL TLS URL (секрет).
- `APP_ENV=demo`, `DEMO_MODE=true`, `DEMO_LOGIN_ENABLED=true`: стенд жюри.
- `ATTACHMENT_STORAGE=database`: устанавливается launcher.
- `API_PROXY_SECRET`: случайный серверный секрет, минимум 32 символа.
- `NEXT_PUBLIC_DGIS_MAP_KEY`: браузерный ключ 2ГИС, задать перед сборкой.
- `OPENAI_API_KEY`, `ASSISTANT_ENABLED=true`, `CLASSIFIER_MODE=llm`:
  внешние модели; ключ только серверный.
- `DB_CONNECTION_TIMEOUT_MS=15000`: запас для пробуждения Neon.

`RENDER_EXTERNAL_URL` задаёт HTTPS origin; cookies Secure. Для другого
домена задать точный `APP_ORIGIN`. Не доверять IP заголовкам без проверенной
настройки ingress. Гости пока делят лимиты; вошедшие пользователи имеют
собственную квоту помощника.

## Проверка опубликованного приложения

Проверить readiness, главную, регистрацию и вход. Создать синтетическую
идею с геометрией и файлом; подать, назначить сотрудника, уточнить
и дать PUBLIC ответ. Снова войти жителем, проверить ответ и уведомления.
Чужой пользователь не должен получить приватную карточку, файл
или INTERNAL комментарий. После redeploy проверить ту же идею,
геометрию и SHA-256 скачанного файла.

Секреты, dump, uploads, `.data`, кэши и промежуточные презентации
не публикуются в GitHub. Результаты проверок хранятся отдельно.

## Бесплатные ограничения

[Render Free](https://render.com/docs/free) засыпает после 15 минут простоя
и имеет временную файловую систему. Открыть сайт заранее перед показом.
Бесплатный Render Postgres истекает через 30 дней, поэтому используется
Neon. Объём Neon Free — 0.5 GB; большой объём файлов потребует другого
постоянного хранилища. AI и 2ГИС зависят от квот/разрешений провайдеров.
